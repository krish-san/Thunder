# ⚡ Thunder - A Shooting Game

Welcome to **Thunder**, a fast-paced 2D shooting game built with **Python + Pygame**!

It’s a small personal project of mine where you move around, dodge enemies, and shoot stuff. Simple controls. Retro vibes. Pure fun.

---

## 🎮 What's This Game About?

It’s a top-down shooting game where:
- You move around using arrow keys or WASD
- Press the spacebar to fire bullets
- Enemies come in waves
- Your job? Survive and score high

No complicated mechanics, just shoot and survive heh.

---

## 🚀 How to Run It (Step-by-step)

### 🧑‍💻 1. Clone the Repository

```bash
git clone https://github.com/krish-san/Thunder.git
cd Thunder
```

---

### 🐍 2. Install Pygame

Make sure Python (3.7 or above) is installed. Then install Pygame using pip:

```bash
pip install pygame
```

---

### ▶️ 3. Run the Game

Just run the main file:

```bash
python main.py
```

The game window will launch, and you're good to go!

---

## ⌨️ Controls

- **Move:** Arrow keys or W/A/S/D  
- **Shoot:** Spacebar  
- **Quit:** ESC or close the game window
